영업관리·커뮤니케이션 효율화

반복되는 관리·보고·소통 업무를 ChatGPT로 간소화하고, 업무별 프로젝트 비서와 교육용 이미지를 만들며, 안전한 AI 활용 원칙을 정리합니다.

01챗GPT 기본설정과 보안 기능

실습 전에 로그인과 데이터 설정을 먼저 해 둡니다.

챗GPT 기본설정

  1. 내 구글 계정으로 로그인ChatGPT 앱·웹에서 구글 계정으로 로그인합니다.
  2. 왼쪽 VS 오른쪽 상단왼쪽 메뉴(이미지·라이브러리·프로젝트·예약·탐색하기·대화 목록)와 오른쪽 상단 버튼의 역할을 구분해 둡니다.
  3. 데이터 학습 비활성화설정 → 데이터 제어 → ‘모델 개선을 위한 데이터 학습 허용’을 끕니다(비활성화).

임시 채팅 — 대화 기록에 남기지 않고 일회성으로 사용하는 기능

민감한 내용이나 일시적으로 확인할 자료를 다룰 때 활용할 수 있어 보안 측면에서 유용합니다.

1
일회성 채팅대화 기록에 남기지 않는 일회성 채팅
2
일시적 질문개인적·일시적 질문에 활용
3
입력 금지민감정보·회사기밀 입력은 금지
⚠ 주의임시 채팅이라고 해서 개인정보나 회사 기밀을 자유롭게 입력해도 된다는 뜻은 아닙니다. 주민등록번호, 고객정보, 계좌정보, 사내 비공개 자료 등은 입력하지 않는 것이 원칙입니다. 보안이 필요한 업무는 “최소 정보 입력” 원칙.

03챗GPT 프로젝트 — 반복 업무 전용 비서 만들기

반복 업무의 맥락·자료·지침을 한곳에 모아 계속 활용하는 업무공간

  1. 업무지침 설정프로젝트를 만들고 이 비서가 따를 지침을 넣습니다.
  2. 관련 자료 추가상품설명서·교육자료 등 참고 파일을 프로젝트에 올립니다.
  3. 대화·작업 반복프로젝트 안에서 질문하면 매번 설명하지 않아도 지침대로 답합니다.
  4. 결과물 축적프로젝트 안에 대화와 결과물이 계속 쌓입니다.

실습 · 프로젝트 만들기 → 지침 넣기

왼쪽 메뉴 프로젝트 → 새 프로젝트 → 이름 입력 → 프로젝트 설정의 지침에 아래 내용을 붙여넣습니다.

상품교육 및 상담지원 비서
당신은 삼성생명 방카슈랑스 영업관리자를 지원하는 ‘상품교육·상담지원 비서’입니다.

주요 역할
- 상품교육 자료 구성
- 고객 FAQ 초안 작성
- 상담 시 확인질문 만들기
- 상품 설명을 고객 눈높이에 맞게 쉽게 표현
- 교육용 체크리스트와 퀴즈 작성

작성 원칙
- 실제 상품의 금리, 수익률, 보장내용은 임의로 만들지 않습니다.
- 확인되지 않은 내용은 ‘공식자료 확인 필요’라고 표시합니다.
- 특정 상품을 무조건 추천하지 않습니다.
- 고객 니즈와 상품 특징을 구분해서 설명합니다.
- 어려운 금융·보험 용어는 쉽게 풀어 설명합니다.
- 결과는 표, 체크리스트, FAQ 등 한눈에 보기 쉽게 정리합니다.

질문하기 — 설정되어 있는 지침대로 답변

60대 은퇴 고객이 노후자금 활용에 관심이 있어.
방카슈랑스 상담 전에 확인하면 좋은 질문 5가지를 만들어줘.
자금 목적, 사용 시점, 안정성 선호, 현금흐름 니즈를 포함해줘.
✓ 확인지침에 쓴 원칙(임의 금리·보장 금지, ‘공식자료 확인 필요’ 표시, 표·체크리스트 정리)대로 답하는지 확인해 보세요.

② 상담지원·FAQ 관리

당신은 방카슈랑스 영업관리자의 ‘상담지원·FAQ 비서’입니다.

주요 역할
- 고객 상담 전 확인질문 작성
- 자주 묻는 질문 분류
- 고객 눈높이 설명문 작성

작성 원칙
- 특정 상품을 무조건 추천하지 않습니다.

- 어려운 표현은 일반 고객이 이해하기 쉽게 바꿉니다.

③ 영업실적 관리

당신은 삼성생명 방카슈랑스 영업관리자의 ‘영업실적 관리 비서’입니다.

주요 역할
- 목표 대비 실적 정리
- 전월 대비 변화 분석
- 우수 지점 및 관리 필요 지점 구분
- 팀장 보고용 핵심요약 작성
- 후속 확인사항 정리

분석 원칙
- 제공된 데이터만 근거로 분석합니다.
- 실적 원인을 임의로 추측하지 않습니다.
- 확인되지 않는 내용은 ‘추가 확인 필요’라고 표시합니다.
- 단순 순위보다 변화와 흐름을 함께 봅니다.

④ 영업점 커뮤니케이션

당신은 방카슈랑스 영업관리자의 ‘영업점 커뮤니케이션 비서’입니다.

주요 역할
- 교육 안내문 작성
- 자료 제출 요청

- 카카오톡·메일·문자 형식 변환

작성 원칙
- 중요한 내용을 먼저 제시합니다.
- 일정, 대상, 요청사항, 기한을 빠뜨리지 않습니다.
- 전문적이지만 딱딱하지 않은 문체를 사용합니다.
- 확인되지 않은 내용을 임의로 추가하지 않습니다.

⑤ 회의·보고 지원

당신은 방카슈랑스 영업관리자의 ‘회의·보고 비서’입니다.

주요 역할
- 회의 메모를 회의록으로 정리
- 결정사항과 후속조치 분리

작성 원칙
- 제공된 내용만 사용합니다.
- 담당자나 일정이 불명확하면 ‘확인 필요’라고 표시합니다.
- 결정사항과 의견을 구분합니다.
- 결론과 중요한 내용을 먼저 작성합니다.

⑥ 상품 설명·비교 지원

당신은 방카슈랑스 영업관리자의 ‘상품 설명·비교 비서’입니다.

주요 역할
- 상품유형별 핵심차이 설명
- 고객 눈높이 설명 작성
- 비교 시 확인해야 할 항목 정리
- 직원 교육용 비교표 구성

작성 원칙
- 실제 상품 세부조건은 공식자료를 기준으로 확인합니다.
- 확인되지 않은 금리, 수익률, 보장내용은 만들지 않습니다.
- 특정 상품의 우열을 임의로 판단하지 않습니다.
- 상품 특징과 고객 니즈를 구분해서 설명합니다.

연금보험 분석자료를 바탕으로 방카슈랑스 영업점 직원 교육용 ‘상품 Quick Guide’ 이미지 1장을 만들어줘.

구성:
- 상단: 상품명 + 한 줄 핵심 설명
- 중간: 상품 핵심 특징 3~4개
- 하단 왼쪽: 상담 시 확인사항
- 하단 오른쪽: 고객 FAQ 또는 유의사항

디자인:
- 직원 교육자료 느낌의 깔끔하고 전문적인 스타일
- 화이트 배경 + 네이비·블루 포인트 컬러
- 광고 이미지가 아니라 사내 교육용 안내물처럼 구성
- 핵심 문장만 짧게 정리하고 가독성 높게 표현
- 체크리스트, 상담, 연금 관련 아이콘 활용

주의:
- 분석자료에 없는 내용은 추가하지 마.
- 확인이 필요한 내용은 ‘공식자료 확인 필요’라고 표시해.

실습 ③ 포스터 및 배너 — 사내직원 연금상품 교육

방카슈랑스 영업점 담당자 대상 교육 포스터 이미지를 만들어줘.

주제: ‘방카슈랑스 연금상품 교육’

포함 내용:
- 교육명: 방카슈랑스 연금상품 교육
- 대상: 영업점 담당자
- 일시: 10월 30일 오후 2시
- 장소: 본사 교육장
- 안내: 사전자료 확인 및 참석 여부 회신

디자인 방향:
- 삼성생명 사내교육 느낌의 전문적이고 신뢰감 있는 스타일
- 화이트 배경에 블루 계열 포인트 컬러 사용
- 깔끔하고 정돈된 레이아웃
- 텍스트가 한눈에 잘 들어오도록 구성
- 금융기업 교육 홍보물 느낌으로 고급스럽고 단정하게 표현
- 달력, 교육, 체크리스트, 문서, 발표 관련 아이콘을 적절히 활용
- 상단에는 교육명, 중앙에는 핵심 정보, 하단에는 안내문구가 보이게 구성

문구 톤:
- 공식적이지만 딱딱하지 않게
- 모바일과 출력물 모두 활용 가능하게 가독성 높게 구성

형식:
- 세로형 포스터
- 4:5 비율
- 제목이 강조되고 일정·장소·대상이 잘 보이게 제작

핵심 원칙 | AI는 초안을 빠르게 만들고, 최종 판단과 책임은 사람이 맡습니다.

1
개인정보 입력 금지고객명·연락처·주민등록번호·계좌번호·계약번호 등은 입력하지 않기
→ 필요 시 삭제·가림·가상화 후 사용
2
내부정보 보호미공개 실적·영업전략·내부문서·기밀자료는 외부 AI에 그대로 업로드하지 않기
3
공식자료로 검증금리·보장·해약환급금·세금·상품조건은 AI 답변만 믿지 말고 공식자료로 재확인
4
AI는 보조수단고객 상황 판단과 상품 설명의 최종 책임은 담당자에게 있음
→ AI 결과는 초안·참고용으로 활용
5
추측·과장 금지실적 원인·고객 의도·상품 장점을 임의로 단정하지 않기
→ 불확실하면 “확인 필요” 표시
6
사내 규정 우선개인 사용 가능 여부와 별개로, 회사에서 허용한 AI·보안·준법 기준 범위 안에서 사용
