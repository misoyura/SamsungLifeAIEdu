How to use

이렇게 사용하세요

  • 01PART 카드 또는 위 목록에서 필요한 프롬프트를 고릅니다.
  • 02금색 상자의 복사 버튼을 눌러 Gemini·ChatGPT에 붙여넣습니다.
  • 03[ ] 안의 내용은 내 업무 상황에 맞게 바꿔 씁니다.
  • 04강의 페이지 상단 프롬프트만 보기로 프롬프트만 모아 볼 수 있습니다.

꼭 지킬 것

AI는 초안을 빠르게 만들고, 최종 판단과 책임은 사람이 맡습니다

  • 개인정보고객명·연락처·주민등록번호·계좌번호·계약번호는 입력하지 않습니다.
  • 내부정보미공개 실적·영업전략·내부문서는 외부 AI에 그대로 올리지 않습니다.
  • 공식자료 검증금리·보장·해약환급금·세금·상품조건은 공식자료로 재확인합니다.
  • 사내 규정회사에서 허용한 AI·보안·준법 기준 범위 안에서 사용합니다.
